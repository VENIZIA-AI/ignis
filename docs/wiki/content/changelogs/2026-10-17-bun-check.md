# Changelog - 2026-10-17

## The repository type-checks with bun check

<Badge type="tip" text="Enhancement" />

**In one line.** Every type check in the build is now `bun check`, Bun's built-in TypeScript checker, so a build spends far less time before it emits anything.

## What changed

- **`bun check` replaces `tsc --noEmit`** in `make typecheck`, in the first step of `make build`, and in `make lint-scripts`.
- **Same answers.** On every package `bun check` reports exactly what `tsc --noEmit` reports, including errors that come only from compiler options inherited through a tsconfig `extends` chain.
- **Faster.** The kernel's three programs type-check in 0.7 s instead of 3.5 s.
- **`tsc` still emits.** The JavaScript (CommonJS and ESM) and the `.d.ts` files are still produced by `tsc`.

## Who is affected

- **Contributors.** Install Bun 1.4.3 or later; the root `package.json` now requires it (`engines.bun >=1.4.3`).
- **Applications using IGNIS.** No action needed. No package changed.
