# Changelog - 2026-10-18

## IGNIS 0.2.2 is stable

<Badge type="tip" text="Enhancement" />

**In one line.** The prerelease line ends: every package is published under a stable version, and the `latest` tag points at it.

```bash
bun add @venizia/ignis @venizia/ignis-boot
bun add -d @venizia/dev-configs
```

## What changed

- **The `latest` tag moves.** A plain `bun add` resolves the versions below. `@next` is no longer needed.

| Package                                                                       | Version |
| ----------------------------------------------------------------------------- | ------- |
| `@venizia/ignis`, `@venizia/ignis-worker`                                     | 0.2.2   |
| `@venizia/ignis-kernel`, `@venizia/ignis-connectors`                          | 0.2.2   |
| `@venizia/ignis-helpers`, `@venizia/ignis-inversion`, `@venizia/ignis-filter` | 0.2.2   |
| `@venizia/ignis-boot`                                                         | 0.2.1   |
| `@venizia/dev-configs`                                                        | 0.3.1   |

- **Siblings are pinned exactly.** Each published package depends on the exact version of every IGNIS package it uses, so one install resolves one copy of each.
- **The code is the code of the last prereleases.** Nothing changed between the last `0.2.2-N` (and `0.2.1-N` for boot and dev-configs) and these versions. The [earlier entries](./index) describe what the line contains.

## Who is affected

- **An application on a `0.2.2-N` or `0.2.1-N` prerelease.** Move every `@venizia/ignis-*` package to the versions above in one change. A package left on a prerelease installs a second copy of its siblings.
- **A library that peers on IGNIS.** A `^0.2.2` range does not match a `0.2.2-N` prerelease. Move the peer range and the application together.
