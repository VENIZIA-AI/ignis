# Changelog - 2026-10-26

## The wiki's claims were checked against the code

<Badge type="info" text="Bug Fix" />

**In one line.** A page that stated something the code does not do now says what the code does. Only readers are affected.

## What changed

- **Claims removed.** The performance numbers and popularity claims that no benchmark or source backed are gone.
- **Facts corrected.** The supported runtimes, the boot modes, the CRUD routes (nine on a `defineCrudController`, with the real preset imports) and the setup steps were checked against 0.4.3. The first tutorials follow the renamed setup heading.
- **What is not finished is said.** The authentication card of the home page says Casbin authorization is experimental and the OAuth2 hook is an empty stub.
- **Other frameworks.** The pages no longer compare IGNIS with, or credit, other frameworks.

## Who is affected

- **You read the wiki.** Nothing to do. No page moved.
