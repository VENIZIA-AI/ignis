# Changelog - 2025-12-17

## Inversion of Control Refactor

**In one line.** The dependency injection system moved out of `@venizia/ignis-helpers` into the standalone package `@venizia/ignis-inversion`.

## What changed

- **New package.** `@venizia/ignis-inversion` holds the dependency injection primitives. It has no dependency on the rest of the framework apart from `lodash`, `reflect-metadata` and `zod`.
- **Old path removed.** The `helpers/inversion` directory of `@venizia/ignis-helpers` no longer exists.

## Who is affected

- **Code that deep-imports `@venizia/ignis-helpers/src/helpers/inversion`.** It no longer works; update the import (below).
- **Code that imports from `@venizia/ignis`.** Re-exports are kept where available.

## Breaking changes

> [!WARNING]
> Deep imports to `helpers/inversion` within `@venizia/ignis-helpers` no longer work.

**Before:**
```typescript
import { inject } from '@venizia/ignis-helpers/src/helpers/inversion';
```

**After:**
```typescript
import { inject } from '@venizia/ignis-inversion';
// OR via re-exports (if available)
import { inject } from '@venizia/ignis';
```

If you use the dependency injection system directly, install the new package:

```bash
npm install @venizia/ignis-inversion
```
