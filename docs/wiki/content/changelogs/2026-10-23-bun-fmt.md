# Changelog - 2026-10-23

## devz lint and make format with `bun fmt`

<Badge type="tip" text="Enhancement" />

**In one line.** The formatting step of `devz lint` and the Makefile calls `bun fmt` instead of the `oxfmt` binary, and your formatted files do not change.

## What changed

- **`devz lint` formats with `bun fmt`.** The third step is `bun fmt --no-script --config .configs/formatters/oxfmt.config.mts`, with `--check` unless you pass `--fix`. Each pattern in `.configs/formatters/.ignore` now reaches it as `--ignore-pattern`.
- **Same files, same config.** `bun fmt` reads your `oxfmt.config.mts` and formats natively. Measured on the IGNIS repository: no file differs from what `oxfmt` produced, in 21 projects.
- **Bun 1.4.4 is the floor.** `bun fmt` is new in 1.4.4; `@venizia/dev-configs` now declares `"bun": ">=1.4.4"`.

## Who is affected

| You have | Do this |
|---|---|
| A project that runs `devz lint` | Use Bun 1.4.4 or newer. No other action |
| A `fmt` script in `package.json` | `bun fmt` would run it; `devz lint` passes `--no-script`, so it still formats. Prefer not to name a script `fmt` |
| `oxfmt` in `devDependencies` | Keep it for now: the config file imports from it |

## Details

- `bun lint` is not in a stable Bun yet, so oxlint and ESLint stay.
- Not changed: the config files, `oxfmtConfigs`, `browserOxfmtConfigs`, `prettierConfigs` and the `oxfmt` dependency. A later release moves the options into a `[fmt]` table in `bunfig.toml`.
