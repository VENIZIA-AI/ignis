# Changelog - 2026-10-23

## Formatting moves to `bun fmt` and `bunfig.toml`

<Badge type="warning" text="Breaking Change" /> <Badge type="tip" text="Enhancement" />

**In one line.** `devz lint` and the Makefile format with `bun fmt`, the format lives in one `[fmt]` table in `bunfig.toml`, and the oxfmt presets are gone.

```toml
# bunfig.toml
[fmt]
printWidth = 100
singleQuote = true
arrowParens = "avoid"
flavor = "oxfmt"
```

## What changed

- **`devz lint` formats with `bun fmt`.** The third step is `bun fmt --no-script`, with `--check` unless you pass `--fix`. Each pattern in `.configs/formatters/.ignore` reaches it as `--ignore-pattern`.
- **The format is one table.** `bun fmt` reads `[fmt]` in the `bunfig.toml` of the folder it runs in or of any parent, so one root file serves every package. The table above gives the output `oxfmt` produced; `flavor = "oxfmt"` keeps it that way once `oxfmt` is no longer installed. Without it Bun formats like Prettier.
- **More than code is formatted.** `devz lint` and `make lint` also check every `.json`, `.jsonc`, `.yml`, `.yaml`, `.css`, `.html` and `.vue` file; Markdown and languages `bun fmt` does not support, such as `.astro`, are not formatted. A file a tool regenerates on its own (drizzle-kit snapshots) goes in `.configs/formatters/.ignore`.
- **`package.json` keys are sorted.** `bun fmt` orders the keys like `sort-package-json` and alphabetizes the dependency blocks. Set `sortPackageJson = false` in `[fmt]` to keep your own order.
- **Bun 1.4.4 is the floor.** `@venizia/dev-configs` declares `"bun": ">=1.4.4"`.
- **The `oxfmt` config files are gone.** Bun loads an `oxfmt.config.mts` when it finds one, and fails if `@venizia/dev-configs/formatters` no longer resolves.

## Breaking changes

> [!WARNING]
> `@venizia/dev-configs` no longer exports `oxfmtConfigs`, `browserOxfmtConfigs` and `prettierConfigs`, and the `@venizia/dev-configs/formatters` subpath is removed. The `oxfmt` and `prettier` peer dependencies are gone, and `eslintConfigs` (and `ReactEslintConfigs`) no longer include the Prettier rule or its `eslint-plugin-prettier` and `eslint-config-prettier` dependencies.

**Before:**

```typescript
// .configs/formatters/oxfmt.config.mts
import { defineConfig } from 'oxfmt';
import { oxfmtConfigs } from '@venizia/dev-configs/formatters';

export default defineConfig(oxfmtConfigs);
```

**After:**

1. Add the `[fmt]` table above to the `bunfig.toml` at the root of your repository.
2. Delete every `.configs/formatters/oxfmt.config.mts`; keep `.configs/formatters/.ignore`.
3. Remove `oxfmt` from your `devDependencies` and your catalog.
4. Use Bun 1.4.4 or newer.
5. A project that sorts Tailwind classes adds `sortTailwindcss = true` and installs `tailwindcss`; one that must not sort `package.json` adds `sortPackageJson = false`.

## Who is affected

| You have | Do this |
|---|---|
| A project that runs `devz lint` | The steps above |
| JSON, YAML, CSS, HTML or Vue files, or a `package.json` out of sort-package-json order | Run `devz lint --fix` once; the lint fails until then |
| A `fmt` script in `package.json` | `bun fmt` would run it; `devz lint` passes `--no-script`, so it still formats. Prefer not to name a script `fmt` |
| The VS Code Oxc extension for formatting | It formats with `oxfmt`, which is no longer a dependency; format with `bun fmt` or `devz lint --fix` |
| A project that used the Prettier lint rule | Drop `prettier` from its dependencies |
