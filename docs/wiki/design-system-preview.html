IGNIS Design System

Mọi giá trị bắt nguồn từ chuẩn: body 16px, type scale Major Third 1.25, spacing 8-point grid, contrast WCAG 2.1 AA (4.5:1 chữ thường / 3:1 chữ lớn), measure ≤ 70ch, line-height body 1.6.

Reading
Measure & rhythm
Độ dài dòng quyết định mỏi mắt. Giới hạn prose ≤ 70ch.
Dòng văn bản nên dài 50-75 ký tự (66 là tối ưu - Bringhurst). Khối này giới hạn max-width: 70ch, line-height 1.6, căn trái. Quá dài gây mỏi khi nhảy dòng; quá ngắn phá nhịp đọc.

Quy chuẩn rút gọn

  • Body16px / lh 1.6
  • Measure (prose)≤ 70ch
  • Type ratio1.25
  • Spacing grid8pt (4 half)
  • Contrast tối thiểuAA 4.5:1
  • Radii8 / 12 / 16 / 24
