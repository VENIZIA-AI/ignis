# Fonts of the shared wiki theme

Both families are licensed under the SIL Open Font License 1.1, which allows bundling and
redistribution.

| Files | Family | Source |
|---|---|---|
| `inter-display-{400,500,600,700}.woff2` | Inter Display (Inter, by Rasmus Andersson) | The files venizia.ai serves from its own `/fonts`, read 2026-10-26 |
| `jetbrains-mono-latin-{400,500}-normal.woff2` | JetBrains Mono (by JetBrains) | The latin subset of the `@fontsource/jetbrains-mono` package |

The files are copied byte for byte into every wiki with the rest of the shared folder; replace them
only in VULCAN's canonical copy.
